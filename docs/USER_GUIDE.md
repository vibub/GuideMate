# 使用指南

随引（GuideMate）默认打开 B 站。工程名、启动入口及既有资料目录继续使用 `GuideMate`。

## 安装与启动

适用于 Windows 10 1809 及以上版本、Windows 11（x64）。需要 [.NET 10 Desktop Runtime（Windows x64）](https://dotnet.microsoft.com/download/dotnet/10.0) 和 [Microsoft Edge WebView2 Runtime](https://developer.microsoft.com/microsoft-edge/webview2/)；发布包不包含 .NET 运行时，也不需要安装 SDK。若缺少运行时，启动入口会显示提示和官方下载链接。安装后重新打开随引，程序不会自动安装运行时。

从 GitHub Releases 下载 `GuideMate-版本-win-x64.zip`，完整解压后运行 `Start-GuideMate.cmd` 或 `GuideMate.exe`。不要只提取单个 EXE。若从源码启动，先安装 .NET 10 SDK，再运行仓库根目录的 `Start-GuideMate.cmd`；`./scripts/Start-GuideMate.ps1 -Build` 可强制从源码构建。

首次启动默认打开 B 站首页。右上角文件夹按钮可打开本地视频，地址栏可访问其他网页；侧栏的“打开验证样例”会播放 40 秒离线视频。也可通过 `--media 视频路径` 直接打开本地视频。

## 播放与字幕

随引控制顶层及同源、跨域或嵌套 iframe 中的 HTML5 视频；网站脚本、沙箱和媒体权限仍可能限制操作。

在 B 站播放器中开启字幕后，网页字幕会同步到侧栏和浮窗，支持新版 AI 字幕、双语字幕及旧版播放器；菜单和 AI 图标不会当作字幕。网页关闭字幕时，同步文字会清空。也可导入 SRT、VTT 或 B 站 JSON 字幕；导入的字幕优先显示，切换视频后清除。字幕延迟为正数时推迟显示，负数时提前显示。基于字幕词语的战斗暂停与淡化默认关闭。

## 热键与临时倍速

默认热键如下；设置页显示当前生效的组合。

| 热键 | 操作 |
| --- | --- |
| `Ctrl+Alt+Space` | 播放 / 暂停 |
| `Ctrl+Alt+Left / Right` | 后退 / 快进 |
| `Ctrl+Alt+Up / Down` | 增加 / 减少倍速 |
| `Ctrl+Alt+Shift+V` | 按住临时倍速 |
| `Ctrl+Alt+PageUp / PageDown` | 上一集 / 下一集 |
| `Ctrl+Alt+Shift+I` | 沉浸模式 |
| `Ctrl+Alt+D` | 全屏弹幕开关 |
| `Ctrl+Alt+H` | 隐藏 / 恢复 |
| `Ctrl+Alt+P` | 鼠标穿透 |
| `Ctrl+Alt+F10` | 紧急恢复 |

若 `Ctrl+Alt+F10` 被占用，随引会尝试 `Ctrl+Alt+Shift+F10`；实际组合以侧栏和设置窗口显示为准。两组都不可用时不能启用穿透。紧急恢复会退出沉浸，并解除穿透和 X 光。

在设置页点击热键输入框即可录制键盘组合或 Mouse4 / Mouse5，也可加 Ctrl、Alt、Shift。录制侧键时将鼠标留在设置窗口内。Esc 取消；保存后生效。录制期间普通全局热键暂时释放，紧急恢复键保留。未绑定的鼠标输入透传；绑定侧键在鼠标钩子可接收时接管其默认前进 / 后退动作。如果鼠标驱动将侧键映射为键盘键，请录制实际键盘组合。

鼠标侧键通过后台原始输入接收，兼容其他程序的鼠标监听；开启 BetterGI 或将焦点留在游戏时不需要重新录制。若游戏或 BetterGI 以管理员权限运行且仍有问题，先正常退出随引，再以管理员身份运行同一个 `Start-GuideMate.cmd`，继续沿用原资料；不要换成隔离测试目录。原神前台、物理侧键、鼠标驱动和权限组合仍需实测。如果两边绑定同一侧键，原始输入不能阻止另一程序执行它自己的动作。

临时倍速默认 2x，按住达到 400 毫秒后触发，设置范围为 100 至 2000 毫秒。它可以和一个普通操作共用同一热键：短按只执行普通操作，长按只进入临时倍速，松开后恢复原倍速。单独设置的临时倍速键必须长按才触发。两个普通操作不能共用热键。切换前台、导航、紧急恢复或修改热键会结束临时倍速；被取消的短按不会补发操作。

## 窗口与沉浸模式

标题栏横线按钮用于最小化并保留任务栏入口；旁边的收起图标用于隐藏到托盘。托盘双击、“恢复窗口”菜单或隐藏 / 恢复热键可找回窗口，最小化前的正常或最大化状态会保留。字幕浮窗随主窗暂时隐藏，恢复后按原开关显示。最小化和隐藏不会主动暂停视频，但网站或浏览器可能限制后台播放。

“窗口”设置提供“不置顶、沉浸置顶、始终置顶”三档。沉浸置顶只在沉浸期间生效；字幕浮窗的置顶策略独立设置。沉浸小窗和字幕 / 方向浮窗默认不显示在 Windows Alt+Tab 列表中；此选项默认开启，可在“设置 → 沉浸小窗”关闭；保存后生效并在重启后保留。隐藏沉浸小窗时也会移除其任务栏按钮，可用原有热键或托盘找回；退出沉浸后主窗口恢复任务栏和 Alt+Tab 入口。

沉浸模式隐藏工具栏，鼠标箭头保持可见。网页原生进度条在鼠标静止 1.8 秒后隐藏，鼠标活动时重新显示，拖动期间保持显示；退出沉浸后恢复播放器原本的控件策略。左上角拖动图标在鼠标进入小窗时出现，拖动期间保持可见；拖到屏幕边缘不会触发 Windows 贴靠流程。沉浸小窗的位置和尺寸独立保存，隐藏、最小化、退出再进入沉浸或重启后沿用；退出沉浸恢复原普通窗口的位置、尺寸和最大化状态。

主窗口与沉浸小窗的四边、四角均可调整大小；右下角超出屏幕或任务栏时，可从其他边角缩放。普通窗口自由调整宽高，沉浸小窗按当前视频长宽比缩放，避免窗口比例不匹配造成黑边；源视频自带的黑边仍会保留。小窗缩放也不会触发 Windows 分屏，最大化时隐藏缩放手柄。

小窗底边保留 3 DIP 进度线：绿色部分代表当前播放位置，点击或拖动可跳转，悬停显示目标时间。左上角也会短暂提示热键操作和当前倍速。

在“设置 → 沉浸小窗”中可设置小窗透明度（0%–80%），并开启鼠标 X 光、调整圆形半径（20–200 DIP，默认 70）。设置保存后生效并在重启后保留。X 光只作用于沉浸小窗：鼠标所在视频区域形成中心完全透明、外沿柔和羽化的圆孔；鼠标离开后恢复。它只渐变透明度，不模糊视频；拖动手柄、缩放边缘和底边进度仍可操作。透明区域的点击会落到下方应用。

## B 站分集与弹幕

“上一集 / 下一集”支持 B 站新版 video-pod 分 P 和旧版分集列表。沉浸状态、列表折叠或隐藏时仍可切换；首集和末集不循环，也不会跳到无关推荐。YouTube 站点选择器及通用 `rel=next/prev` 入口也可识别。网站 DOM 或权限变化会影响兼容性。B 站新版分 P 使用当前视频的标准 `p` 参数网址切换，保留来源参数并清除旧时间定位。

B 站沉浸时，已开启的普通文字弹幕可显示在小窗所在的整块屏幕上。弹幕层透明且鼠标穿透，播放状态和倍速随视频同步；暂停时弹幕暂停，跳转、切集或导航会清理旧弹幕；隐藏、最小化或退出沉浸也会收起弹幕层。必须先开启 B 站自身弹幕开关。设置 → 全屏弹幕可调显示区域（屏幕顶部 10%–100%，包含底部固定弹幕）、不透明度（0%–100%）、字号（50%–200%）和速度（0.5x–2x）。速度同时影响滚动弹幕移动和固定弹幕停留时间，并叠加视频播放倍速；此设置独立于小窗透明度。普通模式下切换只更新偏好，不会进入沉浸。

当前适配播放器筛选后显示的普通文字弹幕；高级脚本与特效不会搬到桌面。

## 字幕与方向浮窗

通过“跟随 → 字幕与方向浮窗”显示提示。方向和来源保持单行，字幕使用可用宽度自然换行；无字幕时浮窗收紧高度，长字幕可滚动。右下角手柄只调整宽度，高度继续自动适应字幕内容。拖动或调整结束即保存位置和宽度，关闭再开或重启后恢复。设置可分别调整字幕字号与方向字号（12–48，默认 16 和 21），以及字幕窗口透明度（0%–80%）；透明度保存后立即生效并在重启后保留，取消不改变原值。字幕透明度独立于主窗口和沉浸小窗，旧资料默认保持不透明。

普通窗口、最大化窗口、网页聚焦、沉浸模式和 iframe 中，播放器隐藏鼠标时均会保护光标可见。普通网页仍保留链接、文本输入和缩放等原生光标行为。

## 视觉方向提示

随引可识别原神和终末地攻略视频中的小地图玩家箭头。校准时选择对应游戏类型并框选箭头，可保留边距或选择作者提供的小地图放大预设；游戏类型和选区一起保存。原神识别青色箭头，终末地识别带黄色光晕的白色箭头。

### 本地视频

打开本地视频后，在“视觉”页选择“校准并分析本地视频”。分析使用本机 OpenCV，不上传视频，也不调用付费模型。离线分析需要已有 FFmpeg 与相邻的 ffprobe；若自动查找失败，也可选择已安装的 `ffmpeg.exe`。识别缓存依据视频路径、大小和修改时间，移动或替换视频后需重新分析。

### 在线视频

打开 B 站等 HTML5 攻略视频，在箭头清晰可见时选择“视觉 → 校准在线视频”，框选箭头并点击“保存并启用”。随引每 0.5 秒识别当前画面，不需要下载整段视频或安装 FFmpeg。受跨域限制时会改为捕获 WebView2 当前显示的播放器画面；小窗太小、箭头被遮挡或播放器画面不完整时可能识别失败。

校准选区和北向参数会长期保存。切集、换网址及参数、清晰度变化、刷新、重启时沿用原选区；分辨率变化时按比例保留位置和大小。只有点击“保存并启用”才会更改已存选区；取消不会更改。暂停和跳转按视频时间更新方向；未识别时显示未识别，不沿用旧方向。隐藏或最小化时暂停采样并清空方向，恢复后继续。

浮窗和校准步骤见[原神视觉说明](GENSHIN.md)及[终末地适配说明](ENDFIELD.md)。箭头识别和视频方向提示不等于实机角色朝向、绝对地图坐标或路线匹配；这些能力仍未实现。识别效果取决于箭头清晰度、画面大小、遮挡和角度。

## 浏览器缓存清理

“设置 → 浏览器缓存”提供“立即清理缓存（保留登录）”。点击后立即清理 WebView2 磁盘缓存及网站 CacheStorage；保留 Cookie、LocalStorage、IndexedDB、保存的密码和浏览器偏好，也不更改随引的热键、收藏、进度及窗口设置。清理不会刷新网页或重建资料目录；部分网页资源在下次访问时需要重新下载，缓存会继续生成。取消设置不会撤销已经执行的手动清理。

“定时自动清理缓存”默认关闭，可选择每天、每 3 天、每周或每 30 天，保存后生效。首次开启或更改周期从保存时开始计时；每次清理成功后重新计时。软件运行时每分钟检查到期任务，播放或拖动进度时延后至暂停/空闲；软件关闭期间不运行后台任务，下次启动补做已到期清理。设置中显示上次清理与下次计划时间，重启继续沿用。

## 软件更新

“设置 → 软件更新”显示当前版本，提供默认开启的“启动时检查更新”和“检查更新”按钮。开关在保存设置后生效，旧资料缺少该字段时默认开启。托盘菜单也提供手动检查入口。启动检查在后台进行，网络失败不阻塞启动；手动检查会显示最新版本、无公开版本或失败原因。自动检查只查询 `vibub/GuideMate` 的最新公开正式 Release，不选择草稿或预发布版。

发现新版本后弹窗显示版本号和 Release 更新说明。点击“稍后”继续使用；点击“下载并更新”打开独立更新程序。下载期间主程序仍可使用；完整 ZIP 通过 SHA256 校验并准备就绪后，主程序保存设置和进度并正常退出，更新器再覆盖安装。可以在覆盖开始前取消，安装期间不能退出。网络失败、校验失败不会改动旧程序；文件替换失败会恢复原程序，若恢复受阻则显示并保留备份目录。

更新完成后显示“启动随引”和“退出”。选择启动时继续使用更新前的资料目录；选择退出或关闭窗口都不会启动软件。

也可直接运行程序目录下的 `updater\GuideMate.Updater.exe`，确认安装目录，在版本框填写公开 Release 标签（例如 `v1.0.1`）后下载并覆盖安装；留空使用最新正式版。指定版本允许安装旧版本或公开预发布版。可从命令行预填：

```powershell
.\updater\GuideMate.Updater.exe --install-dir 'D:\Apps\GuideMate' --version v1.0.1
```

独立运行时，请按界面提示正常退出随引，避免文件占用；更新器不会强制结束进程。更新程序同样需要 .NET 10 Desktop Runtime。它从临时目录运行，因此也能替换自身；正常退出后清理本次暂存文件，仅在恢复失败时保留备份供处理。

## 用户资料与更新

默认资料目录为 `%LOCALAPPDATA%\GuideMate`。显式使用 `--data-dir 路径` 后，随引会在 `%LOCALAPPDATA%\GuideMate\active-profile.json` 记录选择；之后运行启动脚本或新版程序时仍使用原目录。设置在 `settings.json`，网页登录资料在 `WebView2` 子目录，视觉缓存也留在用户资料中。资料目录不可用时程序会报错，不会静默创建空白资料。

更新前正常退出随引，再更新程序和资源。旧版是多文件发布时，建议将新版完整解压到新的程序目录，避免覆盖后遗留旧 DLL；新程序仍会沿用原用户资料。不要用发布包覆盖或清理用户资料目录。

`--isolated` 用于隔离检查，会使用独立资料目录且不更改正式资料选择。若未提供 `--data-dir`，随引会分配新的临时目录。更多隔离桌面检查要求见[构建与验证](TESTING.md)。

## Chrome B 站登录同步

Chrome 登录同步仅接入 B 站。扩展注册、配对及真实账号导入均需要用户明确授权；不读取其他站点、Chrome 密码或整份浏览器配置。合成 Cookie 测试不代表真实账号已完成登录同步。详细步骤和限制见[Chrome B 站登录同步](CHROME_SYNC.md)。

# 原神地图跟随（实验功能）

首版把攻略视频中的当前位置投影到本机游戏左上角小地图：青色点表示攻略位置，超出范围时显示边缘方向箭头。采用图像特征匹配，不读写游戏内存，不控制游戏角色。

## 使用步骤

1. 打开攻略视频，进入随引“视觉 → 原神地图跟随”。
2. 导入有权使用的同区域地表底图（PNG/JPEG/BMP，边长不超过 8192 像素）。选择未经拉伸、北向朝上、尽量没有标注的地图纹理。首版不附带第三方底图库；不支持直接使用任意攻略路线图或带大量图标的网页截图。
3. 框选攻略画面中**整个圆形小地图的外接正方形**，玩家箭头位于中心，保存选区。原始地图宽度至少 96 像素，建议使用高清攻略。旧的箭头朝向选区独立保留。
4. 点击“框选游戏完整小地图”，在 15 秒内切换到原神。程序读取前台游戏画面后打开框选窗口，框选并保存。
5. 点击“启动地图跟随”，保持随引攻略小窗可见，切回原神。连续两帧定位通过后出现标记。
6. 使用“停止地图跟随”关闭功能。重启软件保留底图路径与选区，但不会自动开始屏幕采集。

底图保留在用户选定位置；程序仅保存路径。移动该文件后需要重新导入。地图设置保存时沿用原资料目录，不重置热键、收藏、进度、窗口偏好或网页登录资料。

## 首版范围

- 仅验证单个地表区域的二维地图定位，两路都要求北向固定、中心玩家箭头清晰。不同地图或楼层不能比较；地下、特殊地图、大地图拖动缩放、完整路线预分析尚未实现。
- 游戏需窗口化或无边框，保持小地图无遮挡。采集的是前台游戏区域的屏幕像素，其他软件覆盖在小地图上会影响识别。浮层自身通过 Windows 截图排除属性防止污染识别。
- 浮层要求 Windows 10 2004 或更新版本。独占全屏、HDR、显卡滤镜和跨显示器行为需要实机验证。
- 攻略暂停后目标保持在视频当前位置；玩家继续更新。切集、跳转、传送或匹配丢失后重新确认，不沿用失效位置。
- 随引隐藏或最小化、游戏不在前台、画面过期时隐藏标记。浏览器跨域导致只能截取播放器预览时，小窗太小会丢失地图纹理，需要放大播放器。
- 每轮约 400 毫秒调度一次，识别串行且不堆积；实际速度依赖底图、视频分辨率和机器性能。识别结果超过 1.2 秒即不再显示。坐标显示为底图像素，不能解释为游戏米数或高度。
- 匹配器独立实现，没有复制 BetterGI 代码，也没有打包其地图资源。

## 验证边界

自动测试使用有已知坐标的合成底图，覆盖双路定位、缩放压缩、中心遮挡、空白及无关画面拒绝、跳变确认和旧配置兼容。桌面浮层测试使用独立测试窗口，验证不抢焦点、原生样式、物理坐标和截图排除。

这些测试不等同于真实 B 站攻略、真实原神位置精度、物理按键或游戏前台兼容性验收。上线实际使用前，需要使用同一地表区域的真实攻略和游戏画面测量定位成功率、误差及帧率影响。

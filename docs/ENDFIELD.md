# 终末地攻略方向适配

参考攻略合集：<https://www.bilibili.com/video/BV1erdJBHE5v>。本机验证使用用户提供的 `02.mp4`，个人视频和截图不随仓库分发。

## 使用

打开本地视频，进入“视觉 → 校准并分析本地视频”，将游戏选为“终末地”。此合集可先选“月月放大小地图”；其他作者、HUD 或比例请手动框选白色玩家箭头并保留四周边距。在箭头清晰出现的时间读取预览，再分析完整视频。

在线视频使用“视觉 → 校准在线视频”，选择“终末地”、框选箭头，点击“保存并启用”后继续播放。原有实时取帧、切集、跳转和隐藏恢复流程共用；只更换识别器。校准中的游戏类型、相对选区与北向一起保存，刷新、切集、分辨率变化和重启继续沿用。换到其他游戏需要手动保存对应校准，导航不自动替换既有选区。

只有地图北向固定时才输出八方位。作者叠加了东西南北的放大图可使用北向 0°；旋转地图需取消“地图北向固定”，此时只输出画面角度。

## 识别与资料兼容

终末地标记为白色凹箭头，外有黑边及黄色光晕。通过 HSV 白色掩膜、四顶点轮廓、尾部凹口、尖端/翼部几何和局部黄色光晕识别朝向。圆形图标、无凹口三角形、缺少光晕、触边、无玩家标记或无法判断的画面拒识；不补用上一帧方向。较小的在线视频画面使用同一识别流程。

原神继续使用原来的青色轮廓和形状模板。旧在线校准及离线缓存没有游戏字段时默认原神；保存终末地校准不会重置热键、收藏、历史、窗口状态、旧校准表或浏览器资料。本地缓存仍绑定视频路径、长度和修改时间，重新校准取消时不替换现有时间轴。

## 验证边界

`02.mp4` 为 1920×1080、60 fps、HEVC/AAC、416.767667 秒。使用 36 个合成旋转、图标/无标记反例和 9 张真实抽帧验证，其中 5 张保留帧按尖端与凹口人工近似标注；另将这些保留帧的选区缩到 47×47 后识别，模拟低分辨率取帧。角度检查容许人工标注误差，少量样本通过不等于全视频精度。

完整本地分析产生 834 个采样点，752 个检出、82 个拒识，检出覆盖率约 90.2%，本机此次耗时 49.79 秒。检出覆盖率只表示采样点中识别器输出角度的比例，不能当成准确率。

本机专项桌面检查已验证 HEVC 播放器跳转同步、暂停、无箭头画面清空、两种尺寸的校准布局、游戏选择、取消保留缓存，以及实际浏览器取帧的在线校准。取帧须等跳转完成及当前画面就绪。原神/终末地默认视觉检查 89 项、实际抽帧检查 108 项、核心检查 85 项通过；发布版完整桌面回归 284 项通过。

发布只更新程序、资源及说明。正式资料目录选择、设置 SHA256 与 453 个资料文件的元数据摘要在发布和测试前后保持一致；所有测试使用独立目录并结束退出，正式程序保持关闭。

真实 B 站 `BV1erdJBHE5v` 已在独立 WebView2 资料中加载：640×360 画面在 60 秒检出西向约 271°、300 秒检出北向约 4°，继续播放后方向随时间更新，共 6 项在线检查通过。未导入账号，公开播放仍受 B 站登录与清晰度限制。该合集当前 7 个分 P；发布版在普通与沉浸模式实际完成 p=2 → p=3 → p=2，选集、网址和 CID 同步变化，6 项切集检查通过，保存的终末地校准保持一致。这些检查不能证明整段视频的角度准确率或全部分集布局。

本适配提供攻略侧的方向提示。尚未用终末地游戏前台、物理侧键或实机录像验收；不提供实机位置匹配、角色自动控制或视觉战斗识别。实际 B 站播放、切集和实时方向需单独记录，离线结构或浏览器捕获的本地画面不能替代真实网站证据。

## 复验

默认视觉 Specs 包含两种游戏的合成旋转和拒识检查，无需私有视频。实际样本可在独立目录执行：

```powershell
dotnet run --project tests/GuideMate.Vision.Specs/GuideMate.Vision.Specs.csproj -c Release -- --endfield-frames artifacts/endfield-analysis --endfield-video D:/Downloads/02.mp4 --data-dir artifacts/endfield-analysis
```

提供 5、30、60、120、180、240、300、360、400 秒处的 `endfield-时间.png` 抽帧。完整缓存生成后，以 `--smoke-test --endfield-vision-probe --data-dir 独立测试目录 --media D:/Downloads/02.mp4` 验证播放器、方向同步、校准窗口、取消及网页取帧。不得将测试目录保存为正式启动资料目录。

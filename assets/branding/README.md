# 随引图标

`guidemate.svg` 是可编辑的矢量母版，无字体、外链或位图依赖。

沿用应用强调色松绿 `#137C66`，白色开放窗口勾出 G 的轮廓，薄荷绿 `#BBF7D0` 的箭头朝右上指引，呼应悬浮视频与攻略导航。圆角底板与粗线条适合 Windows 任务栏、托盘及快捷方式。

- `guidemate.png`：512 × 512 透明背景预览。
- `guidemate.ico`：16、20、24、32、40、48、64、128、256 像素，供 EXE、窗口和托盘使用。
- 修改 SVG 后，在可解析 `sharp` 的 Node.js 工具环境中执行 `node scripts/Generate-Icon.cjs`，重新生成 PNG 和 ICO；普通构建直接使用已提交资源，无需安装图像工具。

# 原神样本目录

这里仅提供样本准备说明。个人攻略录像、截图和分析结果保留在本机，不随源码提交或发布包分发。Git 忽略此目录内 README 以外的内容。

如需验证实机跟随，请准备有权使用的 1 至 3 分钟游戏录像和对应攻略片段，并说明能对齐的时间、路线、分辨率、Windows 缩放、窗口模式、小地图旋转设置及游戏版本。保留小地图与必要 HUD，遮挡 UID、账号、聊天和支付信息；不要提供密码、登录二维码或 Cookie。

当前实现是攻略视频中的玩家箭头识别，不包含实机位置匹配、角色/镜头方向分离或视觉战斗检测。具体能力和取样建议见 [视觉说明](../../docs/GENSHIN.md)。默认 CI 只需要合成夹具，不依赖个人样本。
